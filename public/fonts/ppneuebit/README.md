# PP Neue Bit (logo)

Header wordmark only — Figma **2358:1143**.

## Files

- `ppneuebit-bold.otf` — **PP Neue Bit Bold** (OpenType)

OTF is a valid web format and works in all modern browsers. For a smaller
download, you can convert to WOFF2 and add it as the first `src` in
`src/styles/base/_fonts.scss`.

## Usage

Wired via `--font-logo` in `src/styles/tokens/_typography.scss` — used on
`.header__logo` and `.mobile-menu__logo` only. Accent headlines still use
`--font-pixel` (Pixel Font7).
